# AUTO INTEL

Интеллектуальная платформа для поиска, анализа и оценки автомобильных объявлений на российском рынке. Цены — в рублях, интерфейс — на русском языке.

Сейчас готов только каркас проекта. Объявления с Авито, Дрома, Auto.ru и Telegram ещё не подключены. Платные сервисы и API-ключи на этом этапе не используются.

Полная спецификация: [PROJECT_SPEC.md](PROJECT_SPEC.md).

## Что уже есть

- Next.js (App Router), React, TypeScript, Tailwind CSS.
- Тёмная цветовая палитра в `src/app/globals.css`. Цвета заданы один раз и дальше используются по всему интерфейсу.
- Пустые папки под будущие части системы. Кода интеграций в них нет.

## Как открыть проект на компьютере

В папке проекта (`C:\dev\auto-intel`) выполните:

```bash
npm run dev
```

Затем откройте в браузере [http://localhost:3000](http://localhost:3000).

Остановить сервер: в том же окне терминала нажмите `Ctrl+C`.

## Структура папок

```text
src/app/                    страницы сайта
src/components/layout/      оболочка и боковое меню
src/components/listings/    карточки объявлений
src/lib/sources/            адаптеры площадок (пока пусто)
src/lib/agents/             AI-агенты (пока пусто)
src/lib/market/             расчёты цены, ликвидности и прибыли
src/lib/db/                 доступ к базе данных
src/types/                  общие типы данных
supabase/migrations/        будущие миграции PostgreSQL
```

Секреты, когда они появятся, хранятся только в `.env.local`. Этот файл не попадает в Git. Образец имён переменных без значений — `.env.example`. Сейчас заполнять его не нужно.
